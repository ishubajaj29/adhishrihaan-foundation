# Adhishrihaan Foundation Homepage

A static homepage replica for Adhishrihaan Foundation built with HTML, Bootstrap, custom CSS, and a small JavaScript enhancement layer.

## Included sections

- Navbar
- Hero section with CTA buttons
- Mission statement
- What We Do
- Our Focus Areas
- Shrihaan Sahyog Grant
- Events tab section with carousel
- Footer

## Tech used

- HTML5
- Bootstrap 5
- Bootstrap Icons
- Google Fonts
- Vanilla JavaScript

## Run locally

1. Open `index.html` in a browser.
2. No build step or installation is required.
